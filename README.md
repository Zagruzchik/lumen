# Lumen — FLAC-плеер для Android

Офлайн-плеер для своей музыки: FLAC до 24 бит / 192 кГц, без пауз между треками, стеклянный интерфейс, цвета из обложки, синхронные тексты песен.

## Что есть в 0.1 (MVP)

- Библиотека из системной медиатеки + свои папки (через выбор папки)
- Вкладки: треки, альбомы, исполнители, папки, любимое; поиск с транслитом («kino» найдёт «Кино»)
- Плеер: размытая обложка на фоне, свечение, свайп обложки для смены трека, волнистый прогресс, значки качества (FLAC · 24 бит · 96 кГц · Hi-Res)
- Gapless, вывод 24 бит (float), пауза при отключении наушников, аудиофокус
- Уведомление и экран блокировки с обложкой
- Очередь (переход, удаление, перестановка), «Играть следующим», «В конец очереди»
- Тексты песен: .lrc рядом с файлом или LRCLIB, с подсветкой строки и перемоткой по тапу
- Таймер сна с плавным затуханием
- Открытие аудиофайлов из проводника и мессенджеров
- Очередь и позиция восстанавливаются после перезапуска

## Сборка

Android Studio (Ladybug или новее) → Open → `./gradlew assembleRelease`.
APK собирается автоматически в GitHub Actions при каждом пуше в `main`.

Стек: Kotlin, Jetpack Compose, Media3 ExoPlayer, Room, Haze.
